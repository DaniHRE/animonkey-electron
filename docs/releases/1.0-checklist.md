## Decisões de produto pendentes

- **Assinatura Windows:** permanece pendente. (A) assinar instalador e executáveis com identidade de publicador verificada, com custo e manutenção de certificado/chaves; (B) distribuir sem assinatura, com alertas de confiança/identidade desconhecida no Windows. O updater não exige certificado para Windows, mas isso não remove os alertas de distribuição; não inventar identidade de publicador.
- **Canal estável:** `main` é a fonte estável; Windows x64 será distribuído por GitHub Releases. Push em `main` só gera CI/artifact; uma release estável publicada com tag SemVer alcançável por `main` é o que disponibiliza versão ao updater. Outros sistemas/canais seguem fora da 1.0 inicial.
- **Auto-update:** implementado pelo `autoUpdater` do Electron com `update.electronjs.org`, que consome releases estáveis públicas SemVer. A verificação ocorre apenas em Windows x64 empacotado; aplicação baixa em segundo plano e solicita reinício. Teste de ponta a ponta e atualização/rollback continuam pendentes em VM.
- **Pipeline:** workflow `.github/workflows/release-windows.yml`: push em `main` ou `release/**` valida e compila; publicação de release estável validada anexa Setup, `RELEASES` e pacote completo. O build de `release/**` passou no [run 44857046242](https://github.com/DaniHRE/animonkey-electron/actions/runs/44857046242). Somente a branch release recebeu push; não há merge, tag ou release pública. A integração e validação do canal estável continuam pendentes.
- **Monitoramento externo:** sem serviço externo para a 1.0 inicial; revisão manual periódica de providers/contratos. Reavaliar serviço de alertas após haver operação e volume que justifiquem esse custo.
- **CSP de embeds:** (A) manter HTTPS amplo, que tolera rotação e inclusão rápida de hosts de providers, mas amplia a origem permitida; (B) allowlist explícita de hosts, mais restrita, exigindo atualização do app quando providers alterarem domínios.
- Outros sistemas/arquiteturas, importação direta do perfil web e enriquecimentos AniZip adicionais seguem condicionais. Watch Together, admin, páginas institucionais e métricas web seguem fora do escopo desktop.
