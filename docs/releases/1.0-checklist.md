### What Authenticode and SmartScreen do

- Authenticode verifies the signing certificate chain and the integrity of the signed file, and lets Windows display the verified publisher identity. It does not certify that the software is safe, malware-free, or high quality, and it does not guarantee a SmartScreen warning will disappear. Signing is not required by Squirrel or update.electronjs.org.
- Microsoft Defender SmartScreen considers both publisher reputation and the reputation of the specific file hash. A new signed binary can still be shown as unrecognized. Consistent signing can allow publisher reputation to build across versions; unsigned builds have to build reputation separately for each new file. Microsoft publishes no exact reputation threshold or guaranteed timeline.
- OV and EV signatures now have the same SmartScreen reputation behavior for first downloads. Microsoft states that EV no longer bypasses SmartScreen; do not purchase EV solely to suppress the first warning. Windows policy or Smart App Control can still block files that lack a trusted signature/reputation.
- The current Electron Forge guide says Azure Trusted Signing “gets rid” of SmartScreen warnings. That statement is broader than Microsoft's current guidance. Use Microsoft's current [SmartScreen reputation guidance](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation) for user-facing expectations.
