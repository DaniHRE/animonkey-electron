# Animonkey v1.0.3 Release Candidate

## Status

Version 1.0.3 is the selected stable release candidate. Distribution targets Windows x64 through the existing unsigned Squirrel.Windows workflow.

## Candidate scope

- Custom Windows title bar and in-app back/forward navigation, with restoration of the last visited internal route.
- Settings reorganized into sections, with unavailable caption preferences hidden until they can be configured.
- Local persistence of the Vidstack volume preference.
- Client-side IndexedDB caching for Anivexa episode lists, with expiry based on airing data and hourly retries after a scheduled episode is missing.
- A refreshed update center that identifies the installed version and provides a compact, selectable version history.

The feature work started from `dev` at `b6f19f8`. The candidate also incorporates `main` at `b5a9cc4` to preserve the published closeout history and the configured `dev`-to-`main` package pre-build path.

## Promotion path

Promote the candidate with a pull request from `dev` to `main`; the CI Windows package pre-build is configured specifically for that branch pair. Then create `v1.0.3` on the promoted commit and dispatch `release-windows.yml` from `main` with that tag. The workflow validates the tag and version, rebuilds and verifies the Windows package, and creates a GitHub draft with the three Squirrel assets. The draft must be reviewed before publication.
