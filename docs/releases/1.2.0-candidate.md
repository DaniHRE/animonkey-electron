# Animonkey v1.2.0 Release Candidate

## Status

Version 1.2.0 is the proposed next minor release after v1.1.0. The backwards-compatible action-feedback, notification-center, and header-search refinements add user-facing behavior and fit a minor version increment. Distribution remains Windows x64 through the existing unsigned Squirrel.Windows workflow.

At candidate preparation, the work was on the local `release/1.2.0` branch, based on local `dev` at `367c444`. It combines the notification work from `feat/discord-disc-36-toast-feedback` with the search refinements from `feat/discord-disc-35-search-refinement`. The owner authorized integration into `dev`, promotion to `main`, creation of `v1.2.0`, and publication on 2026-11-25. At the time of this note, the changes had not yet been pushed, tagged, or published. The combined Windows x64 Squirrel package was built and verified in a temporary QA worktree; this agent did not install or distribute it.

## Candidate scope

- Immediate action feedback for meaningful success, refusal, and failure outcomes.
- A local action-history category that remains until users explicitly delete entries.
- A floating notification center with independent action, system, anime/episode, and update categories.
- Bottom-right toast stacks and Motion transitions for toasts, the notification panel, and header search suggestions, with reduced-motion and keyboard support.
- A refined header search focus state, tactile press feedback, animated suggestions, and clearer selected-result styling without changing the existing AniList or keyboard behavior.
- Existing local episode alerts, update notifications, and best-effort remote-feed behavior.

GitHub issue [#9 — Refactor notifications and provide feedback for user actions](https://github.com/DaniHRE/animonkey-electron/issues/9) complements the newest Discord request catalogued as DISC-36 in [the feature backlog](../discord-feature-backlog.md).

## Known limitations and operational checks

- Action feedback is stored in the local IndexedDB notification store and is kept until the user deletes it. Other notification kinds retain their existing bounded retention and remote-feed expiry behavior.
- Action records are local to the current profile and are not included in account synchronization or account exports.
- The development and packaged panels have been visually reviewed, including category typography, anime poster/title/relative-time details, and mark-all placement. Agent-run runtime verification covered a successful Watch Later toast at the bottom-right and packaged header search suggestions with keyboard selection. The owner also reported that the remaining notification, refusal/error, history, and installed-app update flows were manually tested and working; this agent did not repeat those checks.
- GitHub issue [#9](https://github.com/DaniHRE/animonkey-electron/issues/9) remains open during candidate preparation and must be closed only after the release ships.
- The application installer remains unsigned under the established distribution model.
